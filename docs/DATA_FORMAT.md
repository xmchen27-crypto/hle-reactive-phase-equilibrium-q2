# 数据与格式说明

本仓库参考本地提供的【0914】HLE训练数据构造任务说明，整理单道物理化学数值计算题。

- 题目与解答以英文为主，采用纯文本与 LaTeX。
- 行内公式使用 `$...$`，独立公式使用 `$$...$$`。
- 题干保留指定的 SI 单位、数值精度和绝对容差。
- `data/problem.json` 保存题干、解答、标准答案、单位及按原顺序排列的数值判定项。
- 三个数值判定项均须满足各自的绝对容差。`expected_values` 是原标准答案的舍入值，不是本次新求解的结果。
- 原任务说明中的每字段 500 字符属于建议；本次保留完整题干和推导，未据此删减。原标准答案长度不超过 200 字符。

本次整理核对了字段提取、公式源码、答案长度、单位与容差的对应关系。未新增模型作答记录或难度达标结论。
